# Noto Sans SC — campus text subset

Source: Google Fonts, https://github.com/google/fonts/tree/main/ofl/notosanssc
Original file: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf
Accessed: 2026-09-09. License: SIL Open Font License 1.1 (OFL.txt).

The local variable WOFF is a glyph subset of the original font, preserving weights 100–900. The subset covers every character in school.astro, school.ts, school-scene.ts, campus.ts, campus-panorama.json and printable ASCII at the time of delivery. Regenerate when introducing new campus text. FontTools pyftsubset was used with --text-file, --flavor=woff and --layout-features='*'. The page loads this file locally; no visitor request to Google Fonts is needed.
