# 东数西算人才培养基地 · 一期数字孪生

## Direction contract

范围为 `/society/`。用户本期要求以六张现场照片和已确认的走廊动线替换旧概念园区，同时沿用深海蓝数字孪生外壳。当前表面是照片参照的一期线性楼层剖视与室内导览，突出教学、科研和算力人才培养场景。其他路由保持其独立视觉体系。

七个导览节点依次为基地入口、成果展示、软件技术、中门大厅、大数据技术、系统运维、人工智能。进入基地面向前方：第一段左成果展示、右软件技术；第二段左右均为软件技术；继续为中门大厅；大厅前方左右大数据技术；再前为系统运维；末端左右人工智能。十间模型房间按该动线作示意排布，系统运维左右暂定。尺寸、房间实际总数与设备重复数量未经实测或台账核验。

空间造型使用照片可见特征：白色基地门头、双玻璃入口与连椅；成果展示大屏、沙盘和交流桌；实训室双侧长桌、透明蓝绿布线通道、蓝帘与教学屏；人工智能白蓝终端；大厅发光展柱、灰色石材地面与格栅顶。模型由 Three.js 几何构建，不使用生成式效果图。页面提供十张真实照片对照，并保留原始公众号二维码。

## Surface behavior

桌面保留左侧动线、中央剖视、右侧照片档案与底部七项导航。地标、左侧动线、底部导航、档案和模型选区同步。节点选择聚焦；“进入空间查看”进入当前空间，入口使用专用外部近景，成果展示使用较高机位，其余为室内视角。

场景状态通过 `data-mode` 与 `twin-mode` 同步：overview 对应剖视工具选中，top 对应俯视，interior 时两者均取消选中。切换剖视/俯视返回整体空间，并分别将标题同步为“一期空间总览”或“一期空间总览 · 俯视”，避免残留室内标题；重置返回一期总览。室内只显示当前所属空间，自动显示其顶棚；“剖视显示顶棚”只决定非室内视图的顶棚显示偏好。另有空间名称、透明通道与布线开关。

1100px 及以下地图位于面板上方，底部导航固定；600px 及以下为单列阅读流，七项导航采用最小 68px 宽的横向滚动布局，页尾预留固定导航与安全区。手机照片完整包含显示。减少动态效果下镜头直接定位，界面禁用 CSS 动画/过渡；巡游为用户启动后的每 6.5 秒节点切换，不自动旋转场景。

无 WebGL 时保留文字、照片和节点导航；禁用三维视角、进入空间、巡游、重置及图层工具。无脚本环境提供全部空间文字。
